BASIC CALCULATOR PROJECT

Files:
- index.html: calculator structure
- style.css: calculator design and responsive layout
- script.js: calculator operations and keyboard support

Features:
- Addition, subtraction, multiplication, division and percentage
- Clear (AC) and delete (DEL)
- Decimal numbers
- Keyboard input support

How to run:
Open index.html in a browser.

How to publish on GitHub Pages:
Upload these files to the root of a public GitHub repository and select
Settings > Pages > Deploy from a branch > main > /(root).

Project technologies: HTML, CSS, JavaScript.
