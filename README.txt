EASY PERSONAL PORTFOLIO WEBSITE
================================

Files:
- index.html       Main portfolio website
- style.css        Website design and responsive layout
- script.js        Mobile menu, demo contact form and calculator interaction
- task-manager.html Extra small task-manager demo linked from Projects

HOW TO RUN:
1. Download and extract this ZIP.
2. Open VS Code.
3. Choose File > Open Folder and select the extracted easy_portfolio_website folder.
4. Open index.html.
5. Right-click index.html > Open with Live Server (if installed).
   If Live Server is not installed, double-click index.html to open it in your browser.
6. Scroll through Home, About, Skills, Projects and Contact.
7. In Projects, click "Try calculator above" and use the calculator buttons.
8. Click "Open demo" under Student Task Manager to add/check/delete tasks.

BEFORE PRESENTING:
- Replace sample email with your own email in index.html.
- Edit the name, education, location, and skill descriptions so they are accurate for you.
- The contact form is a demo only and does not send email.
- Present this as a practice portfolio project, not as a project completed during an internship if it was not.

TECHNOLOGIES:
HTML = structure
CSS = styling and responsive layout
JavaScript = menu, calculator and demo form interactions
localStorage = used by the separate task-manager demo to save tasks in the same browser
